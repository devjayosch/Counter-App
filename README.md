# Counter App

A simple counter app built with **HTML, CSS and JavaScript**.

You can increase, decrease and manually change the counter. The current number is also saved using **LocalStorage**, so it stays there after refreshing the page.

## Features

* Increase the counter
* Decrease the counter
* Set a custom number
* Saves the counter with LocalStorage

## Technologies

* HTML
* CSS
* JavaScript

## How to use

1. Clone the repository:

```bash
git clone https://github.com/devjayosch/Count-App.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it.
